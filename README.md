# 语音输入法

一个基于 Web Speech API 的语音输入法产品，帮助用户提高文本输入效率。

## 功能特性

### 核心功能
- ✅ **语音识别**：实时将语音转换为文字
- ✅ **多语言支持**：支持中文、英文、日文、韩文
- ✅ **连续识别**：支持长时间语音输入
- ✅ **实时结果**：边说边显示识别结果
- ✅ **文本编辑**：支持手动编辑识别结果
- ✅ **文本复制**：一键复制到剪贴板
- ✅ **文本下载**：保存为 TXT 文件
- ✅ **历史记录**：自动保存识别历史
- ✅ **字数统计**：实时显示字数

### 技术优势
- 🚀 **快速响应**：使用浏览器原生 API，无需服务器
- 🔒 **隐私保护**：所有识别在本地完成
- 💰 **零成本**：无需付费 API
- 📱 **跨平台**：支持 Windows、macOS、Linux
- 🎨 **美观界面**：现代化 UI 设计

## 使用方法

### 1. 启动应用
直接在浏览器中打开 `index.html` 文件即可。

### 2. 开始语音输入
1. 点击"开始语音输入"按钮
2. 允许浏览器访问麦克风
3. 开始说话，文字会自动出现在文本框中
4. 点击按钮停止录音

### 3. 设置选项
- **识别语言**：选择要识别的语言
- **连续识别**：开启后可长时间录音
- **实时结果**：显示临时识别结果

### 4. 文本操作
- **复制**：将文本复制到剪贴板
- **清空**：清空文本框内容
- **下载**：保存为 TXT 文件
- **历史记录**：点击历史记录可加载之前的内容

## 使用技巧

### 提高识别准确率
1. 在安静的环境中使用
2. 说话清晰、语速适中
3. 使用标准普通话或英语
4. 避免背景噪音

### 高效输入
1. 使用连续识别模式进行长文本输入
2. 利用历史记录快速复用内容
3. 结合键盘编辑修正识别结果
4. 使用下载功能保存重要内容

## 注意事项

1. **麦克风权限**：首次使用需要允许浏览器访问麦克风
2. **网络连接**：部分浏览器需要网络连接进行语音识别
3. **隐私安全**：虽然识别在本地完成，但某些浏览器可能会将音频发送到服务器
4. **浏览器限制**：某些浏览器可能不完全支持所有功能

## 常见问题

### Q: 为什么点击语音按钮没有反应？
A: 请检查以下几点：

1. **浏览器兼容性**：
   - ✅ 推荐使用 Chrome 25+、Edge 79+、Safari 14.1+
   - ❌ Firefox 需要手动启用 `media.webspeech.recognition.enable`

2. **麦克风权限**：
   - 首次使用需要允许浏览器访问麦克风
   - 在浏览器地址栏左侧点击🔒图标，检查麦克风权限是否允许

3. **网络连接**：
   - 某些浏览器的语音识别需要网络连接
   - 确保网络连接正常

4. **HTTPS 要求**：
   - 语音识别需要 HTTPS 连接（localhost 除外）
   - 直接打开本地 HTML 文件（file:// 协议）可能无法使用
   - 部署到 GitHub Pages 即可正常使用

### Q: 说话后没有显示文字？
A: 可能的原因：
- 环境太嘈杂，尝试在安静的地方使用
- 说话语速太快，尝试放慢语速
- 麦克风没有正确工作，检查麦克风是否正常
- 选择了错误的语言，确保选择正确的语言选项

### Q: 识别准确率不高怎么办？
A: 尝试：
- 在安静环境中使用
- 说话更清晰、语速适中
- 选择正确的语言选项
- 使用标准发音
- 避免背景噪音

### Q: 历史记录保存在哪里？
A: 历史记录保存在浏览器的 LocalStorage 中，最多保存 20 条记录。

### Q: 如何在本地测试？
A: 使用本地服务器：
```bash
# 使用 Python
python -m http.server 8080

# 使用 Node.js
npx http-server -p 8080

# 然后访问 http://localhost:8080
```

### 错误提示说明
| 提示 | 原因 | 解决方案 |
|------|------|----------|
| ❌ 不支持 | 浏览器不支持语音识别 | 使用 Chrome/Edge/Safari |
| ⚠️ 需要 HTTPS | 当前不是 HTTPS 连接 | 部署到 GitHub Pages |
| ⚠️ 权限未授权 | 麦克风权限未允许 | 在浏览器设置中允许麦克风 |
| 未检测到语音 | 没有检测到声音输入 | 检查麦克风或说话更大声 |
| 网络错误 | 网络连接问题 | 检查网络连接 |

## 开发说明

### 本地开发
直接修改 `app.js` 文件中的 `VoiceInputApp` 类即可。

### 核心类
- `VoiceInputApp` - 主应用类
- 主要方法：
  - `initRecognition()` - 初始化语音识别
  - `toggleRecording()` - 切换录音状态
  - `onSpeechResult()` - 处理识别结果
  - `saveToHistory()` - 保存历史记录
